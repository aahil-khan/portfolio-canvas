The Shopkeeper is one question from the [[agent-reliability|agent reliability study]], made concrete: can an agent bargain well and still keep a secret? The shop is invented and small. Its rules, prices and thirty-five test customers all come from one spec,[^spec] written so that the tests exist before the agent does.

Read it in order. [[shopkeeper-01|Chapter 01]] says what changed from the first draft. [[shopkeeper-02|02]], [[shopkeeper-03|03]] and [[shopkeeper-04|04]] set up the shop, its thirteen rules and how it bargains. [[shopkeeper-05|05]] is the decision the rest hangs on, with a toy you can haggle with. [[shopkeeper-06|06]] and [[shopkeeper-07|07]] are the tools and the scenarios that attack them, and [[shopkeeper-08|08]] is how a run is graded.

Nothing has run yet. Each chapter says what the spec expects; when v0 runs, the results are written up here, against those expectations.
