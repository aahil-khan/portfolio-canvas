# Lab v2, version B: first slice

Static mockup of the Lab (plan `lab-v2-b-a`, task 1): the home and chapter 05, in two looks.
Fresh code. Nothing here comes from `prototype/lab/`, and there are no npm dependencies.

```bash
node --experimental-strip-types import.mjs   # regenerate content/lab-data.js from the real sources
node bundle.mjs                              # one self-contained file -> ~/projects/scratch/lab-mockups/lab-v2b.html
node bundle.mjs --copy                       # rewrite COPY.md from content/copy.js
cx heavy -- node check.mjs                   # the checklist; ends with LAB-V2B OK
```

`index.html` also opens straight from disk while you work.

| Path | Holds |
|---|---|
| `look.js` | the one owner of the look, theme, Aa and reduced motion; runs before first paint |
| `lab.js` | data helpers, router, bar, pages, previews, the dot, the name |
| `lab.css` | both looks as token sets over one geometry (switching moves nothing) |
| `instruments/` | the lead registry (board, compare, demo, screens, result, key line, opening, install) and the haggle toy; `haggle-core.js` is the spec's pricing logic as a pure module |
| `audio.js`, `player/` | the AudioContext and cues; the side player (radio, noise synthesis) |
| `content/lab-data.js` | generated by `import.mjs`; don't edit |
| `content/copy.js` | every written sentence; `P(...)` lines are proposals, listed in `COPY.md` for veto |
| `content/fixture-kinds.js` | test-only overlay (`?fixture=kinds`), never in the delivered bundle |
| `fonts/` | Space Mono and Reenie Beanie (OFL); Space Grotesk comes from `app/fonts/` |
| `assets/` | the Drag to Workspace demo and Holt screens, re-encoded as WebP |

Query params: `?look=paper|premium`, `?mode=light|dark`, `?theme=<site theme id>`, `?feature=<entry id>`,
`?from=desk`, `?fixture=kinds` (check build only).
