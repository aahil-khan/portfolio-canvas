This fixture note has no ID like T02, so the line above its title names the section and its status instead. Everything else is the same template the chapter uses: the head, the artifact, the body, Related, and nothing that knows which note it is.

## A heading only this fixture uses

The body is short on purpose. It still has one paragraph long enough for the measure rule to read, so the check can prove the column holds its width on a page that was never designed by hand.
